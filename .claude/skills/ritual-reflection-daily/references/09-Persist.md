# Persist

Archive Today.md to Periodic.

## Process

1. Read `00_Brain/Captive/Today.md`
2. Copy to `00_Brain/Periodic/Daily/YYYY-MM-DD.md`
3. Clear or reset `00_Brain/Captive/Today.md` for next day

## Archive Structure

Daily archives go to:
```
00_Brain/Periodic/Daily/
├── 2026-02-21.md
├── 2026-02-20.md
└── ...
```
