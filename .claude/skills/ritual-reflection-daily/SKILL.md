## Template Contract

Today.md has these H2 sections:

| Track | Section | Updated By |
|-------|---------|------------|
| Brief | `## Brief` | Brief phase (review) |
| Goals | `## Goals` | Goals phase (completion status) |
| Calendar | `## Calendar` | Calendar phase (meeting notes) |
| Journal | `## Journal` | Journal phase (reflection) |
| Achievements | `## Achievements` | Achievements phase (wins captured) |
| Relationships | `## Relationships` | Relationships phase (touchpoints) |
| Projects | `## Projects` | Projects phase (progress) |
| (append-only) | `## Changelog` | All phases |

## Reflection vs Planning

Reflection rituals use **explicit inheritance**:
- Show actual GPS/track components from the plan
- Ask which were advanced
- Capture evidence and outcomes
