## Template Contract

Quarter.md has these H2 sections:

| Track | Section | Updated By |
|-------|---------|------------|
| Brief | `## Brief` | Brief phase (review) |
| Goals | `## Goals` | Goals phase (Quest completion) |
| Calendar | — | No quarterly Calendar track |
| Journal | `## Journal` | Journal phase (pivot review) |
| Achievements | `## Achievements` | Achievements phase (leverage) |
| Relationships | `## Relationships` | Relationships phase (network) |
| Projects | `## Projects` | Projects phase (portfolio) |
| (append-only) | `## Changelog` | All phases |

## Reflection vs Planning

Reflection rituals use **explicit inheritance**:
- Show actual Quests from the plan
- Ask which were completed
- Synthesize weekly archives into quarterly patterns
