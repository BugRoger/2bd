# Brief: Reflect Weekly

Summarize the week's events and learnings.

## Context to Load

1. Read `vault/00_Brain/Captive/Week.md` for planned focus
2. Read daily reflections from this week
3. Read other assistant weekly reflections

## Process

1. Gather week summary:
   - What were the highlights?
   - What themes emerged?
   - What surprised you?

2. Generate summary:
   - Week narrative
   - Key wins
   - Challenges faced
   - Next week's carry-forward

## Output

Write to `vault/00_Brain/Synthetic/Assistants/brief/{date}-reflect-weekly.md`:

```markdown
# Brief: reflect(weekly) {date}

## Status
ok

## Section
### Week Summary

{Narrative of how the week unfolded}

### Highlights
- {Highlight 1}
- {Highlight 2}

### Challenges
- {Challenge 1}

### Themes
- {Theme that emerged}

### Carry Forward
- {What needs attention next week}

## Observations
- {Patterns, surprises, learnings}

## Timestamp
{ISO timestamp}
```
