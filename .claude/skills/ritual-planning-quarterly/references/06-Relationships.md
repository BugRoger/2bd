## Process

1. Gather context:
   - All people files (`02_Areas/People/*.md`)
   - Weekly relationship notes from prior quarter

2. Interactive:
   - Ask: "Which relationships are thriving? Which need attention?"
   - Ask: "Are there stakeholder map changes?"
   - Ask: "Who should you connect with this quarter?"

3. Present:
   - Group by relationship type (Team, Peers, Leadership, External)
   - Note status and attention needed
   - Identify gaps
