# Goals

Guide quarterly Quest definition aligned with Annual Goals.

## Load Coach

1. Read `00_Brain/Systemic/Coaching/Goals/quarterly.md`
2. Read `00_Brain/Semantic/Coaching/Goals/insights.md`

## Agent

Use agent specified in coach: **sonnet**

## Process

1. Show context:
   - Annual Goals (from Year.md)
   - Prior quarter archive for continuity

2. Interactive conversation:
   - Ask: "What 3-5 outcomes would make this quarter successful?"
   - For each Quest: "How will you know it's done?"
   - Reality check: "Is this achievable in 90 days?"

3. Finalize Quests:
   - 3-5 Quests with measurable outcomes
   - Each connected to an annual Goal
   - Success criteria defined

## Update Quarter.md

1. Read `00_Brain/Captive/Quarter.md`
2. Replace `## Goals` section with finalized Quests
3. Write entire file back

Proceed to Calendar.
