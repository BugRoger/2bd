# Brief

Synthesize the quarterly brief from hierarchical context.

## Load Coach

1. Read `00_Brain/Systemic/Coaching/Brief/quarterly.md`
2. Read `00_Brain/Semantic/Coaching/Brief/insights.md`

## Agent

Use agent specified in coach: **haiku**

## Process

1. Synthesize from loaded context:
   - Quarter position in the year (Q1/Q2/Q3/Q4)
   - Context from Year (relevant Goals)
   - Prior quarter synthesis (what carried forward)
   - Key constraints or opportunities

2. Present the brief:
   - Strategic framing, not tactical
   - Connect to annual vision
   - 4-6 sentences maximum
   - No interaction — let user absorb

## Update Quarter.md

1. Read `00_Brain/Captive/Quarter.md`
2. Replace `## Brief` section with synthesized brief
3. Write entire file back

Proceed to Goals.
