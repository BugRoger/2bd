# Goals

Guide yearly Compass definition using GPS methodology.

## Load Coach

1. Read `00_Brain/Systemic/Coaching/Goals/yearly.md`
2. Read `00_Brain/Semantic/Coaching/Goals/insights.md`

## Agent

Use agent specified in coach: **sonnet**

## Process

1. Review prior year:
   - What changed, what stayed true

2. Interactive conversation for each component:
   - **Life Compass**: "What values are most important this year?"
   - **3-Year Sketch**: "Where do you see yourself in 3 years?"
   - **Why**: "What's the deeper why behind your goals?"
   - **Anti-Goals**: "What are you NOT willing to sacrifice?"

3. Define Annual Goals:
   - Ask: "What 3-5 annual goals would make this year successful?"
   - Connect each to the Compass

## Update Year.md

1. Read `00_Brain/Captive/Year.md`
2. Replace `## Goals` section with Compass and Annual Goals
3. Write entire file back

Proceed to Calendar.
