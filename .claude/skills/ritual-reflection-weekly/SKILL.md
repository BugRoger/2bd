## Template Contract

Week.md has these H2 sections:

| Track | Section | Updated By |
|-------|---------|------------|
| Brief | `## Brief` | Brief phase (review) |
| Goals | `## Goals` | Goals phase (Major Moves status) |
| Calendar | `## Calendar` | Calendar phase (week meetings summary) |
| Journal | `## Journal` | Journal phase (patterns, growth) |
| Achievements | `## Achievements` | Achievements phase (weekly wins) |
| Relationships | `## Relationships` | Relationships phase (connections) |
| Projects | `## Projects` | Projects phase (progress) |
| (append-only) | `## Changelog` | All phases |

## Reflection vs Planning

Reflection rituals use **explicit inheritance**:
- Show actual Major Moves from the plan
- Ask which were advanced
- Synthesize daily archives into weekly patterns
