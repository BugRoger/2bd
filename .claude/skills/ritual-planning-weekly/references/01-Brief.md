# Brief

Synthesize the weekly brief from hierarchical context.

## Load Coach

1. Read `00_Brain/Systemic/Coaching/Brief/weekly.md`
2. Read `00_Brain/Semantic/Coaching/Brief/insights.md`

## Agent

Use agent specified in coach: **haiku**

## Process

1. Synthesize from loaded context:
   - Week shape (meeting density, focus blocks, key dates)
   - Context from Quarter (which Quests are active)
   - Context from Year (relevant Goals)
   - Key deadlines or milestones this week

2. Present the brief:
   - Narrative form, 4-6 sentences
   - Set the stage for the week ahead
   - No interaction — let user absorb

## Update Week.md

1. Read `00_Brain/Captive/Week.md`
2. Replace `## Brief` section with synthesized brief
3. Write entire file back

Proceed to Goals.
