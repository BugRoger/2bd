# Persist

Archive Year.md to Periodic.

## Process

1. Read `00_Brain/Captive/Year.md`
2. Copy to `00_Brain/Periodic/Yearly/YYYY.md`
3. Clear or reset `00_Brain/Captive/Year.md` for next year

## Archive Structure

Yearly archives go to:
```
00_Brain/Periodic/Yearly/
├── 2026.md
├── 2025.md
└── ...
```
