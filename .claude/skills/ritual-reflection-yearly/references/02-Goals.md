# Goals

Review annual Goal completion against Compass using explicit inheritance.

## Load Coach

1. Read `00_Brain/Systemic/Coaching/Goals/yearly.md`
2. Read `00_Brain/Semantic/Coaching/Goals/insights.md`

## Agent

Use agent specified in coach: **sonnet**

## Process

1. Show the Compass from Year.md:
   - Life Compass (values)
   - 3-Year Sketch (vision)
   - Why (motivation)
   - Anti-Goals (boundaries)

2. Show Annual Goals and review each:
   - For each Goal: "Did you achieve this? [Yes/Partial/No]"
   - "Did you stay true to your Anti-Goals?"

3. Compass reflection:
   - "Did your values hold true?"
   - "Is your 3-Year Sketch still the right direction?"

## Update Year.md

1. Read `00_Brain/Captive/Year.md`
2. Update `## Goals` section with completion and Compass review
3. Write entire file back

Proceed to Calendar.
