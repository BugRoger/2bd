## Template Contract

Year.md has these H2 sections:

| Track | Section | Updated By |
|-------|---------|------------|
| Brief | `## Brief` | Brief phase (review) |
| Goals | `## Goals` | Goals phase (annual completion) |
| Calendar | — | No yearly Calendar track |
| Journal | `## Journal` | Journal phase (leadership journey) |
| Achievements | `## Achievements` | Achievements phase (celebration) |
| Relationships | `## Relationships` | Relationships phase (circle review) |
| Projects | — | No yearly Projects track |
| (append-only) | `## Changelog` | All phases |

## Reflection vs Planning

Reflection rituals use **explicit inheritance**:
- Show actual Compass and Goals from the plan
- Ask which were achieved
- Synthesize quarterly archives into yearly patterns
