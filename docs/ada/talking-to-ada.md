## Slash Commands

| Command | What It Does |
|---------|--------------|
| `/plan` | Start a planning ritual (daily, weekly, quarterly, yearly) |
| `/reflect` | Start a reflection ritual |
| `/project <name>` | Work on a specific project |
| `/person <name>` | Discuss a relationship |

## Conversation Patterns

Ada responds to natural language. You can:

- Ask questions: "What's on my calendar today?"
- Give updates: "I finished the quarterly review"
- Request synthesis: "Summarize my week"

## When to Use Ada

| Time | Command | What Happens |
|------|---------|--------------|
| Morning | `/plan` | Daily planning with brief |
| Before meetings | (automatic) | Meeting prep |
| After meetings | (capture) | Decisions and actions |
| End of day | `/reflect` | Daily reflection |
| End of week | `/reflect` | Weekly review |
