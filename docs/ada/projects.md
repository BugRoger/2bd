## What Projects does

Tracks active project status, identifies blockers, and surfaces next actions.

## Project health

For each active project, Projects tracks:
- Current status (on track, at risk, blocked)
- Recent progress
- Blockers or dependencies
- Next actions
- Target completion date

## Status surfacing

During rituals, Projects:
- Highlights projects needing attention
- Flags approaching deadlines
- Identifies stalled projects
- Suggests priority order

## Actions

| Action | Timescale | What it does |
|--------|-----------|--------------|
| Plan | Daily | Surface today's project priorities |
| Plan | Weekly | Review all active project status |
| Reflect | Daily | Update project progress |
| Reflect | Weekly | Assess project health |

## Integration with Projects hub

Projects works with your `✱ Projects` hub and individual project files in `01_Projects/`.

## What Projects produces

- `Synthetic/Assistants/projects/` — working output
- Projects section in Captive notes
- Status updates to project files
