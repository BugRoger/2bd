## Prerequisites

- [Claude Code](https://docs.anthropic.com/en/docs/claude-code) installed
- An empty folder for your vault (or existing Obsidian vault)

## Step 1: Install 2bd

```bash
claude plugin install 2bd
```

## Step 2: Bootstrap Your Vault

```bash
claude
> /init
```

Ada will guide you through setup. Answer her questions about:
- Where to create your vault
- Your name and role
- Calendar integration (optional)

## Step 3: Run Your First Ritual

```bash
> /plan
```

Ada will run a planning ritual appropriate to the time of day.
